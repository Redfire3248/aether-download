# Aether

**The code editor for everything.** Write code in any language, make games, draw, wire up Arduino circuits and turn it all into real apps, in one free program for Windows.

**[Get Aether](https://redfire3248.github.io/aether-download/)**

This repository holds Aether's website and its installers (see [Releases](https://github.com/Redfire3248/aether-download/releases)). Aether's source code is not here.

Download numbers: [downloads.json](downloads.json) has the total and each version's count, and [downloads.csv](downloads.csv) has the total by day. A GitHub Action updates them once a day.

Extensions are in the [Aether Marketplace](https://github.com/Redfire3248/aether-marketplace).

Aether is free to download and use. All rights reserved.

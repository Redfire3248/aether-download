Pick your Aether

What do you want to make?

Aether

A code editor that does it all.

  • AI that explains, edits and writes tests, with a model on your PC or your own cloud key.
  • A debugger for Python and JavaScript, a fast terminal and Git.
  • One click makes your program a Windows .exe or an Android .apk.
See Aether

Aether Game Maker

Make the game, then play it right there.

  • 2D and 3D scenes, scripts and templates to start from.
  • Draw, animate with bones, make sounds and songs, design the menus.
  • Play with friends over Wi-Fi or online. Export to Windows, Android and the web.
See Game Maker

Aether Lab

Plan it visually. Let the agents build it.

  • Milestones, a task board, a timeline and a canvas that links to real tasks.
  • Any AI: local models, your own cloud keys, Claude Code or Codex.
  • Agents work in a copy. Nothing reaches your files until you accept it.
See Aether Lab

Aether Script

A first language that makes real things.

  • It reads like Python: no brackets to forget.
  • Open a window with buttons or a canvas in a few lines.
  • The same language scripts games in Game Maker.

Aether Script, anywhere

        
Run it without Aether.

        
Aether Script programs run in VS Code and from any terminal too, in windows of their own that Aether Script draws itself.

      

      

        

          
For VS Code

          
Colours, mistakes underlined as you type, the Aether Script icon on .aes files, and a Run button (F5).

          Get the extension
          
In VS Code: Extensions, the … menu, Install from VSIX, then pick the file.

        

        

          
Its own window system

          
The Aether Script runner draws every window itself, with no browser. Save the program and its windows update where they are. Errors show in the window, animation runs at your screen's own rate, and F12 takes a picture.

          Get the runner
          
Windows 10 and 11, 1.8 MB. Double-click a .aes file to run it. Without the runner, windows open with Edge or Chrome.

        

        

          
In any terminal

          
aes run game.aes runs a program, aes check finds mistakes, and aes page makes a web page of it.

          Get aes.js
          
Needs Node.js 18 or newer. On Windows, put aes.cmd next to it.

Early versionAETHER LAB

Think visually. Build with any AI.

A native workspace to plan a project and build it with AI agents: a planner, an architecture canvas, and an agent panel that works with any model. You review every change before it reaches your files.

Download for Windows See how it works

Aether Lab 0.1 is an early version. It works and grows fast; expect changes. Windows 10 and 11, no admin rights.

Three parts, one project

Plan it. Draw it. Let agents build it.

The plan, the diagrams, the files and the agents' work all point at the same tasks, so nothing is just for show.

Planner

Milestones, tasks and subtasks, a board, a list, a timeline and a graph of what depends on what.

Architecture canvas

Draw how the project fits together. Each node can link to a task and to files, and shows that task's status.

Agent panel

Ask, Plan, Agent and Review modes, with @ mentions for files and tasks, and the exact context shown before you send.

The planner

Your plan, always moving.

Drag a card to change its status. Tasks can't depend on each other in a loop, and the usual steps are kept unless you say "move anyway".

  • Overview: the milestone, and what is in progress, blocked or in review.
  • Board, list and timeline, with filters, all from the same tasks.
  • Turn the plan into a document, a prompt or Markdown.

The canvas

Draw the system. Send it to an agent.

18 kinds of node and 10 kinds of link, with groups, frames and auto-layout. Right-click a node to make a task from it or send it to an agent.

  • Nodes show their task's status, so the diagram is a live map of the work.
  • Undo, copy and paste, align and spread, and export to SVG or JSON.

Stay in control

Agents propose. You decide.

Agents change files in a copy of the project. You see every change as a diff and accept it file by file, or part by part.

  • Nothing is overwritten: if the file changed meanwhile, both sides are merged when they touch different lines, or it stops as a conflict.
  • Comment and send it back for another pass, or reject it.
  • Every review is logged, and pending changes survive a restart.

Local first

Your project stays yours.

The plan lives in your project as plain JSON in a .aether folder, so Git can keep it and you can read it without Aether Lab.

  • Safe writes: each file is written beside the old one, checked, then swapped in, with the previous version kept.
  • Files that look like secrets are never sent to a model.
  • Chats, runs and keys stay in Aether Lab's own folder, never in the project.

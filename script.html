.aesAether Script

Reads like Python. Made for making.

Aether's own language. Write a program that opens windows of its own, or a script that brings a game to life. Run it in Aether, in VS Code, or from any terminal.

Get the tools Read the guide

Two kinds of file

One language for programs and for games.

Aether tells them apart by what is in the file. Lines at the top that do something make a program; on blocks make a game script.

Easy to read

Classes, f-strings, list building, match, try and except: what you know from Python, with fewer surprises.

Windows of its own

Window() opens a real window with labels, buttons, inputs, sliders and a canvas to draw on.

Game scripts

Attach a script to a node and fill in on update(dt) and on collide(other). The engine does the rest.

See it

Every example runs as it is.

name = "Aether"
print("Hello,", name)
print("2 + 3 is", 2 + 3)
win = Window("Counter", 300, 200)
win.title_text("Counter")
shown = win.label("0")
count = 0
func add():
  count += 1
  shown.text = str(count)
row = win.row()
row.button("Add one", add)
row.button("Close", win.close)
var speed = 220
var jump = 620

on update(dt):
  if key("arrow_right") or key("d"):
    x += speed * dt
  elif key("arrow_left") or key("a"):
    x -= speed * dt
  if pressed("jump") and on_floor:
    vy = -jump

on collide(other):
  if other.tag == "coin":
    other.destroy()
    game.score += 1
    say(f"Coins: {game.score}")

Aether Script, anywhere

Run it without Aether.

Aether Script programs run in VS Code and from any terminal too, in windows of their own that Aether Script draws itself.

For VS Code

Colours, mistakes underlined as you type, the Aether Script icon on .aes files, and a Run button (F5).

Get the extension

In VS Code: Extensions, the ... menu, Install from VSIX, then pick the file.

Its own window system

The Aether Script runner draws every window itself, with no browser. Save the program and its windows update where they are. Errors show in the window, animation runs at your screen's own rate, and F12 takes a picture.

Get the runner

Windows 10 and 11, 1.8 MB. Double-click a .aes file to run it. Without the runner, windows open with Edge or Chrome.

In any terminal

aes run game.aes runs a program, aes check finds mistakes, and aes page makes a web page of it.

Get aes.js

Needs Node.js 18 or newer. On Windows, put aes.cmd next to it.

Write your first program.

Make a file called hello.aes, write one line, press F5. The guide takes you from there to windows and games.
